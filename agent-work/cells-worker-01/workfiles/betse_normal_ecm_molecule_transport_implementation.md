# Configured general-molecule transport with ordinary ECM

This held source proposal adds the reachable native configured-transporter
branch to the existing supplied FULL/ECM general-molecule composition. It keeps
the general owner independent of the optional GRN owner. It has not been
imported, collected or evaluated scientifically. The new protocol addresses
three concrete risks: ECM exchange indexing, complete transporter cache carry,
and capturing channel/chemistry inputs after transporter writes.

The explicit parents are molecule-dispatch01, manifest
`e51f7eead8d6bfe3a0e4f669005386e6f4271632f0531084754320025b1ed922`,
and transporter03, inputs
`8f0f502049d62344c36df591da920314c54f26b78a1ea6f36f34ea9936af45cd`.
The common rate module, transporter source, Decimal rate reference and rate
protocol are byte-exact between those frozen parents. Prior qualification is
not transferred. The INIT02 composition remains transitively pinned; no live
foreign source or transition successor is implicitly adopted.

The new `bind`, `initialize`, `advance` and `verify` API follows the prior
composition. Its separate input kind adds `transport`, containing explicit
membrane wedge volumes and a normally null `raw_setup_fault`. Wedges must match
the native `0.5*R_rads*mem_sa` expression on the actual supplied geometry.
Configured transporters belong to
`handlers.molecules.network.configuration.transporters` and must match the
actual native general-network section. This first scope permits up to three
ordered, all-target, cell-zone rows. A null list disables this source flag; an
empty list enables an empty native transporter dispatch. The general owner may
itself be disabled independently of GRN. Additional GRN transporters and
subset/expression targeting remain separate bindings.

The source class copies native `Transporter` initialization/targeting and
`MasterOfNetworks.read_transporters`, `write_transporters` and
`run_loop_transporters` executable bodies. The existing primary material,
CaATP and full-field controller bodies remain intact. Native dispatch is:
general clear, transporters, channels, modulators, chemistry/molecular transport;
then the independent GRN sequence. The general current/charge publication is
replaced by GRN when that enabled owner publishes. Publication-off retains the
previous shared epoch. Field inputs bind that exact epoch.

Each general cache owns all public transporter fields, generated equations,
ordered targeting metadata, original cold metadata and the complete flux
vector. Initial flux is literal `None`; successful warm calls require its
presence. Dynamic concentration aliases still point to the actual primary
buffers and molecular owner. Foreign equations, missing fields, changed flux
epochs and arbitrary pump weights are refused before work. The ordinary
`rho_pump=1` is explicit throughout; dormant movement is never activated.

Original semantics remain visible:

- Transporter current is added before reactant and product commits. Failures
  preserve earlier current, material and cache writes without retry.
- Internal sampled membrane writes omit stoichiometric multipliers. The
  independent book predicts this discrepancy separately from bulk amounts.
- Fast ECM `div_env` uses repeated-index assignment and total membrane area per
  site; slow exchange uses the area map. The reference derives its own grid and
  predicts the fast collocation defect. It does not replace either with ideal
  conservative scattering.
- The stored `ignore ECM` value is unused by these native methods. Product Km
  is unused in the final rate; the literal concentration conversion remains
  outside each power.
- Bare transporter valence and molecular `scale_factor` charge/current
  publication conventions are retained. No zero electrical, energy or global
  material residual is imposed.

Fresh Decimal100 and Decimal160 references start at each actual immutable
pre-transporter state. The inherited rate/regulation prefix changes only the
outside sample mapping to ECM sites. Independent ordered commits compare all
species concentration buffers, flux/current frames, per-species bulk and
environment amounts, requested exchange, collocation and membrane-buffer
defects, and source-weighted charge. Existing prefix/CaATP, per-owner channel
and chemistry/molecular transport, deferred commit and full-field checks remain
independently conditioned. There is no carried reference trajectory.

The prospective plan has 60 IDs: 23 positive/disabled/component declarations,
four inherited molecular refusal declarations, two original cold transporter

1306 independent forms and 102 native conditional captures. All are unrun and

The source audit passes 55 regeneration/native/qualified correspondence proofs
and ten compile/global-name/module-export checks. Earlier static audit failures
and corrections are retained. The independently reconstructed native namespace
recompiles authenticated source into fresh classes and imports no production
scientific implementation when later invoked. The release driver is metadata
only and cannot start a scientific round.

Existing channel domains, source failures and numerical budgets are unchanged.
The catalog05 Nav reference refusal and old signed-environment failure remain

molecular pump/gating branches, GRN transporters, profile targeting, ER, flow,
mechanics/noise/events and FAST remain outside this proposal.
