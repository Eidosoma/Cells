# Supplied molecule lifecycle

This proposal composes cold setup, a complete bounded headless INIT prefix,
retained general/GRN reinitialization and an independent three-call SIM material
phase. Native general transporters precede channels and chemistry in both
phases. General and GRN enablement remain independent and stable across this
first boundary. There is no whole physical initializer, event loop or native
persistence claim.

The phase declaration is bound with `lifecycle.init.bind`. Its initializer
returns the actual post-setup binding and state. `lifecycle.init.advance`
preserves the original calendar, source labels, rate caches, complete owner
fields, material buffers and fields. `lifecycle.prepare_complete` admits only
the complete exhausted original INIT calendar. Paused, capped and failed
prefixes have distinct retained evidence and cannot enter the normal handoff.

The transition declaration names that exact INIT binding. Calling
`lifecycle.transition` executes the actual retained owner setup bodies and
returns a SIM state which keeps the INIT artifact separately. Owners, cores
and molecule objects are retained. Configured transporters and channels are
rebuilt through the native readers. `None` and empty configurations keep their
distinct native flags. Native storage clearing resets time lists; it does not
clear concentrations or fluxes. The configured transporter reader has already
rebuilt its flux as `None`. CaATP and NaK rate attributes survive entry, before
the next actual producer call. SIM has its own labels, elapsed material dt,
gate counts and journal.

Cold observation explicitly preserves absent `rho_pump` and `rho_channel`
before their native late writes. Both runtime and independent native captures
retain raw per-owner fields even when a partial object cannot be represented
as a complete cache. Failures preserve original exception chains, source order,
earlier transporter writes, numerical buffers and the last accepted parent.
The Root-reviewed generic capture helper is an explicit new dependency; old
dispatch01 and transport01 test modules are not replaced implicitly.

The first boundary retains declared chemistry, gates and cold-publication
policy. It closes extra static/dynamic noise, interventions, active mechanics,
osmotic coupling, flow, ER, mitochondria and nonunit pump weights. It refuses
latent dictionaries and flag/configuration changes rather than erasing native
state. `fire_events`/`makeAllChanges` equivalence is deliberately outside this
supplied material seam, even when a native SIM configuration has no scheduled
events.

Each proposed accuracy comparison uses fresh Decimal100/160 conditionals from
the actual incoming state. They cover setup, cold owners, calendars, reset
rules, NaK, primary material, CaATP, per-owner transporters/channels/chemistry,
deferred commits and complete fields. Native captures cover local actual owner
boundaries; they are not independent carried trajectories. Numerical budgets,
source defects, existing failures and channel oracle domains are unchanged.
The 54 declared checks, 61 INIT and 66 SIM positive calls, 3006 reference forms
and 177 native conditionals are prospective and unrun.

The new packet explicitly combines transport01 and transition02 source and
adopts only the two reviewed INIT04 reference overrides. Transition02 retains
its historical INIT02 association. The capture profile reuses fixed 64 MiB
byte caps, 16 KiB headers and the format-derived 310689 member bound. It makes
no measured maximum or all-captures-fit claim. Its driver can print metadata
and refuses every scientific launch.
