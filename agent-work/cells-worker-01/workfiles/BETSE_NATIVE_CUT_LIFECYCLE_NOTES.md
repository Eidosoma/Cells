Concrete source risks:

- Native ownership uses a hardcoded special-name set and cell-first length
  tests. np.delete has no axis and flattens matrices. ECM cc_env is removed from
  the special set but still enters the generic length heuristic; coincident
  species/cell counts can corrupt global grid data.
- List branches delete in place, then retain data[index] only, or fail after
  partial mutation. An unmatched nested row can leave data2 unbound or reuse a
  stale result from an earlier row/attribute. Scalar NumPy arrays can fail len.
- initDenv resets current diffusion/weights/TJ/Chi, while the cut method does not
  explicitly rebuild D_env_base or sigma_env/ko_env initializer caches. Recomputed
  profiles write current Dm_cells but the outer makeAllChanges later uses the
  deleted/carried old Dm_base+Dm_scheduled.
- Molecule.remove_cells assigns deleted flux_intra to cc_grad_x, preserving the
  old flux_intra attribute. Real channel.init_channel resets source gate/core
  state; it cannot be replaced by a warm-cache subset remap.
- DEC cut_mesh returns removed edge indices despite its restructure-index
  docstring and documents hanging simplices/edges. ATP release and conductivity
  recomputation in the cut method are commented out.
