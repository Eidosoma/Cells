# Constructor and first pre_mesh preparation

This new-prefix package is static implementation and test preparation only.
No constructor, triangulation, mesh or reference computation has run. Chief
coordinates any future qualification and owns shared status.

B09 already provides reviewed fixed ring/manufactured mesh captures, a merged
square and derived operators. The geometry-initialization adapter authenticates
those fixed captures; it does not authenticate new lattice caller topology or
continued RNG. The lattice02 and image02 reviews are accepted. Reuse those
laws/evidence without counting
B09 generation or RNG-law coverage again.

The native constructor/pre_mesh closure has seventeen methods. The private
production kernel is an attributed source transcription with the original BSD
notice retained. Its math/order is unchanged; owned local RNG, exact deletion
indices, nearest/Delaunay evidence and logging enter through explicit hooks.
No mutable native package object is exposed. The original native oracle uses
authenticated original AST bodies and isolated NumPy/SciPy dependencies.

The entry point requires an owned image prelude, or a separately authenticated
fixed B09 initialization. Caller coordinate/geometry overrides are absent.
Multi-cell calls keep all lattice and bbox occurrences, including duplicates.
The original vstack-transpose/vstack memory layout is reconstructed before the
constructor, so C-order frozen storage does not change subsequent reductions.
Single-cell construction instead generates ring-plus-centre points using the
complete post-lattice stream and the original centroid; unused lattice IDs are
provenance, not deleted physical cells. No reseeding occurs.

The first sequence is close-point marking/deletion, Delaunay, source triangle
metrics and alpha selection. Non-single-cell sanity checking may delete unused
rows and repeat that sequence once; the source flag is set only after the
repeat. Circumcentre-nearest merging follows, then primary edges, directed
mappings, reflected dual vertices and mapped/reoriented dual edges. Original
set enumeration and nearest ties remain; no deduplication or topology repair is
introduced. Exact source deletion indices carry occurrence IDs through every
row mutation, rather than recovering identity from coincident coordinates.

Numeric, ragged and object caches have immutable typed snapshots. Object-array
pointer bytes are never hashed or pickled: dtype/shape/source-strides and each
typed element are retained. Nearest calls, pre-alpha Delaunay arrays, primitive
inputs/results, method boundaries and failed partial caches form a trace.
Native source failures and stricter finite admission have distinct status.
Diagnostic nearest-query infinity sentinels do not become physical measures.

The source cyclic-quad check uses side-derived diagonals and rounded Ptolemy;
it does not test the actual diagonals. `quad_circumc` supplies Brahmagupta area
and a radius-along-AC centre. Those named native quantities remain distinct
from independent general-polygon area/centroid and any true circumcentre.
Directed-only edge lookup, repeated nearest-matched reference-face areas and
source boundary flags are likewise preserved. A raw source cache is not
automatically a physically valid mesh specification.

Independent Decimal100/160 primitive geometry and nearest distance/rank tables
are prepared. Exact-rational circle signs diagnose Qhull topology;
captured topology remains an input, with no independent Delaunay generator or
canonical tie-owner claim. Any independent topology acceptance scope must be
reviewed before qualification. Raw and refined evidence must precede assertions;
an accuracy failure will not be reclassified or retried automatically.

The prepared panel has 22 checks: ten complete source comparisons (five reused
B09 inputs and five owned lattice/image callers), two raw source failures,
four resealed input refusals, and six cache/ownership/layout/stream boundaries.
Raw actual caches precede native execution; native caller arguments, full
native traces and primary/refined reference records precede assertions.
Failure type, stage, message and partial buffers are retained, including partial
independent-reference records if evaluation fails.

Static parsing/compilation and Ruff pass on nine Python files without imports
or test collection. A static AST checker authenticates thirteen native files,
seventeen original methods and ten original helpers, and compares twenty
production functions to the native source after the 22 runtime hooks, two
closed helper imports and declared metadata/zip normalization.
Chief accepted the proposed scope and requested a frozen guarded CPU6 driver and
fresh native/reference replays for static preflight. The launch gate stays false.
The driver requires Chief's preflight receipt, accepted frozen manifest and new
user authorization. Each phase has a 480-second wall limit, 1 GiB summed process

or subsequent run is configured. The terminal inventory excludes exactly the
root result file and includes nested result receipts.

The fresh workers deny production/native package imports before loading their
providers. Native replay compares typed actual and original-native traces;
reference replay evaluates Decimal100/160 geometry/nearest values again and
checks the saved reference buffers and fixed budgets. Raw-source reference
reports describe only the retained prefix, without claiming independent source
failure generation. No provider, worker or qualification driver has been run.
