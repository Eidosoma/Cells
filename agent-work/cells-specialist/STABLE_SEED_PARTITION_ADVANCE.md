# First original interval: source-only adapter proposal

The candidate uses the existing Cells stepping laws and driver semantics:
the original EventGrid interval, control-aware checked RK4, the resolved-tissue
field/RHS composition, complete ledger histories and ordinary checkpoint checks.
It introduces no constitutive equation, physical parameter, geometric inference,
step-size selector or BETSE-equivalence claim. The initial bridge and all its
503 frozen files remain untouched.

The adapter's public gate is closed pending exact accepted initial source-review
and numerical-qualification receipts. A positive independent initial worker
report alone cannot open that gate. The full original worker input/report,
runtime source closure, original initial preparation and explicit caller
acceptance must also bind. Receipt scope is to be pinned explicitly by Chief;
the candidate does not infer approval from unknown future receipt schemas.

One attempt starts at time zero with the admitted quantities, units, all twelve
state fields, forty layout fields and controls carried with exact dtype/byte
checks. The caller selects only the first original boundary, or asks for that
existing boundary; a different endpoint, supplied state/operators or new
physical fields refuses. No layout or concentration is rebased.

The existing Cells checked kernel remains responsible for RK4 arithmetic. Each
trial first runs the existing control-domain guard, which recomputes its field.
Its RHS then recomputes a separate field and derives all twelve rates from that
field, matching the ordinary eager CPU/JAX path. There is no field cache.
Five trial states and each completed field/RHS are retained immediately, with
exact dtype, shape and bytes, before observers or later checks can fail.
The kernel's old-state fallback on rejection is recorded and cannot become an
accepted adapter result. Endpoint acceptance uses the existing two-boundary
material, finite-node capacitor, charge, energy, source-work and dissipation
checks, then the right-continuous endpoint field and ordinary checkpoint check.
The time-zero-only accounting helper is not reused after advancement.

Prospective tests include four comparisons with the existing Cells driver using
previously qualified initial artifacts, exact input/scope refusals, rejected
trial retention and a completed-RHS observer failure. No scientific fixture
generator is supplied. Future execution needs an explicit retained-artifact
index and qualification pins; it cannot pass through missing-input skips.
All tests remain uncollected and unrun.

Refinement has one concrete unresolved validation-scope choice. The frozen
initial worker admits four literal definitions with dt=end=1e-6 seconds.
Common-endpoint smaller-dt comparisons require different sealed initial
preparations and an ordinary driver reaching the same endpoint. They need
either a reviewed initial caller/worker successor or an explicitly reviewed
clock-metadata equivalence contract. The adapter cannot silently subdivide its
original interval, retry, change the caller declarations or inherit initial
qualification across that clock change. No refinement implementation or
qualification claim is made pending that choice.
