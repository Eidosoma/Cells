# Active initialization on explicit finite-ECM polygons

`cells_active_ecm_polygon_initialization@1` binds complete caller-declared active
physiology to the actual cell/bath owners of the frozen finite-ECM partition.
It resolves region volumes, membrane areas/capacitances/paths, orthogonal bath
face areas/distances and explicitly declared ER geometry, then invokes the real
public target-family parser. It never promotes a passive definition by changing
its ID, inserts physiology defaults, rescales inventories or supplies a missing
owner. Frozen active02 and finite-ECM01 sources remain unchanged; their pending
numerical qualification and prior failed evidence are not inherited acceptance.

The [implementation](/home/robert/Cells/src/cells/core/active_ecm_polygon_preparation.py)
accepts the finite-ECM law's immutable request and binding, plus a complete actual
family template with identified geometric references. Its immutable preparation
owns JSON copies, a definition/provenance identity, every conversion certificate,
all caller declarations, cell/bath/membrane/face owner axes and both base bundle
identities. Full re-preparation detects resealed changes. Refusals retain the
complete request, stage, materialized definition and conversion trace when
available, exception type and reason.

## Audited family and topology scope

The selected public ionic@2/@12, calcium@1/@11, ionic finite-fuel@1/@2 and
calcium finite-fuel@1/@5 parsers all retain the resolved passive parser's explicit
extracellular face topology. Their model initialization binds the real bath
nodes and face factors, and their complete initial-domain checks run on the
actual model and controls. The new bridge keeps these existing admissions and
exact nested ionic identities. It supports no additional catalog versions by
fallback.

The two selected open-family identities are supported solely in their existing
explicit empty-reservoir reductions, with actual finite bath flags and null
open-system ceilings. Their public parsers still run. Actual held reservoirs
are a concrete ownership gap here: the frozen finite-ECM law declares finite
polygon compartments and sealed outer/axial boundaries. Adding a held bath would
require an explicit boundary/ownership extension, and is refused without
altering flags, inventories, source geometry or ceilings. Active02's separate
held-reservoir capability does not extend this geometry law.

All existing geometric restrictions remain: one connected convex conforming
cell/bath partition, exact domain exhaustion, no direct cell-cell interface or
inferred cleft, explicit thin membrane paths, and perpendicular bath centroid
links whose common projection lies strictly within the actual shared face.
Every declared bath volume comes from its own polygon extrusion. Each calcium
cell explicitly partitions its total polygon volume into cytosol and ER before
rounding; ionic and chemical cytosol use the same ratio and free-ion amounts.
Internal ER membrane area/path are caller supplied. Each finite-fuel cell owns
one ATP/ADP/Pi pool; Na/K, PMCA and ER pumps consume their own cell's pool, and
regeneration ports retain explicit pool IDs. Selected channels retain their
existing 298.15 K identity and exact zero/one/two-state declarations.
