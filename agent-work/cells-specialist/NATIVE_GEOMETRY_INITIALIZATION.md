# Initial generated geometry into the environment component

This package adds the capture-to-environment adapter; it reuses the reviewed B09
geometry and MT19937 helpers without adding their earlier counts as new coverage.
Chief owns project status in `PROGRESS.md`. ECM02 remains failed39/40 and its
numerical lane is paused for Root's saved-evidence decision.

`src/cells/processes/betse_geometry_initialization.py` binds a complete original
B09 seed recipe, prepares an immutable exact seed/draw state, authenticates its
generated geometry through the fixed reviewed B09 receipt, and builds the
separate environment definition. The adapter accepts manufactured seed clouds
or the native DECMesh ring-plus-centre generator. The source preset named
"single cell" has seven downstream owners for the captured six-sided recipe;
it is not relabeled as one biological cell.

The fixed B09 receipt SHA is
`cbc165a2a899d30136ce3c78224ebec3e9acab9ce11ed08de680a7cd81b6a46f`.
Record bytes, source manifest, exact recipe, retained/removed owner ledger,
constructed points and complete MT19937 states must agree. Initialization is
reauthenticated when used, so resealing an embedded record cannot authorize
changed metrics. Existing `geometry_tissue_preparation.bind_source` recomputes
the bound topology/measures. Actual native cell centres, membrane occurrence
order, midpoints, areas, normals and radial cell volumes are then transferred
from the authenticated capture. There is no caller metric-override input.

Material species, uniform initial concentrations, diffusion, electrical
constants and native `true_cell_size` calibration remain explicitly declared.
The latter is a separate native configuration parameter, not a generated cell
measure. Height, gap and radius come from the authenticated generation recipe.
The environment component re-derives its maps/operators/cache and retains its
strict nearest-tie refusal. Such a refusal is recorded only with independent
ambiguity confirmation; a numerical-accuracy failure cannot become a passing
admission refusal. At least one generated and one manufactured accepted bridge
are required for qualification.

The source map audits full `make_world`: square/HEX lattice x-then-y draws occur
even at zero disorder, then four bounding seeds are appended; full single-cell
world creation also executes that lattice and image prelude before the native
ring constructor. Image/SVG clipping, alpha filtering, merging, close-point
removal and refinement can change topology/order. Those full-world paths are
excluded here. Native topology remains the pinned SciPy1.18.1/Qhull B09 output,
not an independently regenerated triangulation. Exact constructor draws require
the recorded NumPy2.5.3 runtime and complete Gaussian-cache metadata.

Prepared checks compare original constructor arithmetic and complete draw states
with the established independent MT helper and Decimal coordinates, verify
metric transfer against independent polygon/owner calculations, and compare
complete generated-world environment readouts with native and independent
fields. Both rounded reference precisions and raw precomparison arrays are
retained. Frozen sources, the B09 input bundle, runtime files and resource logs
bind the authorized CPU6 run. Chief authorized one adequate bounded qualification
after the user's "lets go"; scientific accuracy failures are preserved without
automatic retry. No whole-cell, biological, field-energy, solver, compiled or
GPU parity is claimed.
