# Protein atlas data

| File | What it is |
| --- | --- |
| `inventory.snapshot.json` | A slim, read-only copy of the Cells law inventory (`cells.protein_catalogue.law_inventory@2`, made on 12 November 2026 at engine `fec863f`). Generated by `tools/import_protein_inventory.py`; do not edit |
| `overlay.json` | The viewer's own layer: districts, plain-language lines, the shape drawn for each kind of unit, link patterns and one recorded rename |

The snapshot is not a catalogue. The catalogue's design is stage 3 of
`docs/PROTEIN_CATALOGUE_PLAN.md`; it has not begun and belongs to the engine. To refresh
the snapshot after the inventory changes:

```bash
python3 tools/import_protein_inventory.py --inventory PATH/law_inventory_v2.json
python3 tools/extract_architecture.py --strict
```

## Sources and licences

| Source | What the snapshot holds from it | Licence |
| --- | --- | --- |
| Cells law inventory | Functional units, laws, statuses, kinds of evidence, assembly statements and notes | MIT, with this repository |
| [UniProt](https://www.uniprot.org/), release 2026_04, read 12 November 2026 | Accessions, protein names and lengths of the candidate gene products: reviewed human entries, and Xenopus laevis entries found by gene name | CC BY 4.0 |
| [RCSB Protein Data Bank](https://www.rcsb.org/), read 12 November 2026 | Titles, methods, resolutions, assembly copies and symmetries, and primary citations of the reference structures | CC0 1.0 |

Cite UniProt as: The UniProt Consortium, "UniProt: the Universal Protein Knowledgebase in
2025", Nucleic Acids Res. 53:D609-D617 (2025), release 2026_04. For the RCSB PDB, each
structure's primary citation is kept with it. Both were checked in stage 1 of the plan.

Nothing is copied from Xenbase, the Human Protein Atlas or the AlphaFold DB. The view only
links to the Human Protein Atlas and the AlphaFold DB. The import tool drops the
inventory's Xenbase identifiers and refuses to write one, and a test checks the result.
