starts and before any registered run. Items 1 to 3 are gaps this author found by reading each rule against an
honest run, and the lead adopted. Item 4 is the lead's.

- **Precedence.** It governs over the tagged files and amendments 1 and 2 where they differ. It differs from the

## 1. Which holders have an `H_<i>` (READOUTS §1, TABLE §3, CRITERIA §3.6)

**The gap.** LAWS §0 calls every node a holder, so the table contract asked for `H_S` in `F7`, where no link touches
the site node S.

**The ruling.** `H_<i>` covers the holders that a link touches or a portion enters. A link whose rate is 0 touches
its ends. So `F7` has `H_A`, `H_B` and `H_K` and no `H_S`, `J0` has `H_A`, `H_B` and `H_K`, and `G1` to `G4` have
`H_K`. Every rule that reads `H_<i>` reads those: class N, class S in arm 5, the sum `H_tot`, and the twins.

**Can a verdict depend on it? Yes.** Without it a table with no `H_S` has a refused readout, and arm 3 is at best
inconclusive.

## 2. Arm 2's exact `H_face` identity, across the exchange (CRITERIA §3.2)

**The gap.** "The sum over the intervals of D of the run's own levels, the exchange's jump left out" does not say
where the interval after the exchange starts. The row at the exchange's time is the state before it (SPEC §1).

**The ruling.** The interval that starts at the exchange's time starts from the post-exchange levels, n_T_1 − sample
+ supplied and n_T_2, formed from that row and the event's own numbers. It does not start from the row at that
time. Every other interval runs from row to row.

**Can a verdict depend on it? Yes.** Read from the row, every honest run with an exchange fails.

## 3. An M1 miss, on any stop (CRITERIA §3.7 and §8)

**The gap.** §8 says that a recorded run's stop counts toward nothing and that M1 applies to it, and not what an M1
miss there does.

**The ruling.** An M1 miss on any stop, a recorded run's included, fails FR-54's stopped-run line. That line reads
the stops of FR-54's own tables, arms 1 and 2 (§8). A recorded run's stop itself still counts toward nothing for its
arm. A judged run's stop still fails its run (D), and an expected stop must still stop.

**Can a verdict depend on it? Yes:** FR-54's, through its third line.

## 4. The invented set holds a near-tight default start (SPEC §8, CRITERIA §10)

**Why.** Amendment 2's disclosure says T4's class B has almost no slack beyond e_round where the affinity is nearly
linear, and that the rehearsal exercises that only if an invented start is of that kind. SPEC §8 did not ask for
one. The lead looked, and the invented set had default-heat starts of other kinds and none of this one.

**The ruling.** The invented set also holds a default-heat start in two equal wells with a level ratio near 1: a
background several times the difference. Its runs are judged, at kh at most 1/64. The references agent adds it to
the invented pair only (`inputs_invented.json` and `reference_invented.json`). No registered file changes.

**Can a verdict depend on it? No.** The rehearsal is evidence for the harness and the bounds (CRITERIA §10). What it
decides is whether a bound is corrected before the registration tag, by §10's route.
