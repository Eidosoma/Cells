## 1. The scale of a case's `B_def` (amendment 5, R8)

**The gap.** R8 gives a case's heats the scale s_F. At a trace start `B_def` is a Taylor-remainder bound (LAWS §2) that
grows as the lower level falls, and it lies many orders above s_F. Its 40 published digits cannot lie within 10⁻³⁸ s_F, so
C0 would refuse arm 1's file for the rounding of a value that nothing reads there: T4 is judged at no trace start.

**The ruling.** R8's "its heats s_F" reads "its heats s_F, and for `B_def` the larger of s_F and its own value".

**Can a verdict depend on it?** Only through C0, before any run: without it C0 refuses arm 1's file. Where `B_def` is read
(T4's class B, at the judged default starts) the moved amount is a small part of either level (SPEC §6's χ), so `B_def` is
below s_F by its formula and its scale is unchanged.

## 2. `J0`'s `n_U_K` (amendment 5, V1)

**The gap.** V1's "`n_U_*` class R" takes in `n_U_K`, which SPEC §4 makes class E: "`J0`'s collector and router heat at
every output".

**The ruling.** In V1, `n_U_*` reads `n_U_A` and `n_U_B`. `n_U_K` stays class E. Nothing published changes class.

**Can a verdict depend on it? Yes, by reading.** V1's words would have let `n_U_K` pass within a rounding bound. It is
judged bit for bit, as SPEC §4 has it.

## 3. P16's rows (amendment 5, L4)

**The gap.** L4's list of the keys of a `plants` row leaves out one that is published.

**The ruling.** P16's rows also hold `heat`, since two heats share a world.

**Can a verdict depend on it? No.** It is a key's name, and item 4 reads it.

## 4. Which run a plant reads (amendment 5, C14)

**The gap.** (`world`, `step_s`) does not single out a run. `F1` at 1.0 s is `F1 h=1.0` and `P8 flow`; `N-buffered` at
0.25 s is the exact and the default j = 2 and `P8 event`.

**The ruling.** C14's "A plant's run is the one its reference entry names by `world` and `step_s`" reads: it is the honest
**judged** run of that world and step, of the kind that CRITERIA §6.1's row names. For P17 that is the exact run, and for
P16 the run of each of its rows' `heat`. C14's rule for twins stands.

**Can a verdict depend on it? Yes,** through a plant's score, and so its request: read from another run of that world and
step, a plant would be formed from the wrong rows and scored with the wrong tolerance.
